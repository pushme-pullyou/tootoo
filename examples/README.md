# Examples

One or two small files of every type TooToo can show, plus folders that exercise the file tree. Use it as a tour, and as the by-eye check before a release.

## What to try

| Folder | Try this |
| --- | --- |
| [docs/](docs/) | Markdown: headings, lists, tables, code. Switch between **Raw** and the rendered page |
| [blog/](blog/) | A folder named `blog` with month folders sorts newest first |
| [code/](code/) | Highlighted source and plain text. Try **Copy** and **Download** |
| [data/](data/) | A CSV opens as a table; JSON and YAML open as code. One CSV is large on purpose |
| [images/](images/) | One picture of each format, and three larger ones |
| [svg/](svg/) | Drawings shown as pictures, with **Raw** showing the source |
| [audio/](audio/) | The audio player |
| [video/](video/) | The video player, and an MP4 playing inside a Markdown page |
| [pdf/](pdf/) | A PDF in its frame |
| [html/](html/) | Web pages shown in a sandbox: their scripts must not run |
| [projects/](projects/) | Folders five levels deep, each with a README that opens when you click the folder |

Also worth a look while you are here: the filter box (press `/`), the arrow keys in the tree, back to top (↑) on a long page such as [docs/markdown-help.md](docs/markdown-help.md), dark mode, and a narrow window.

## Adding an example

Put the file in the folder for its type and add a line to that folder's README saying what it shows. Keep files small: this repo also hosts the releases. For a picture, sound or video that is not your own, add its credit here first.
